# Eval Cases(層 3:流程品質驗證)

5 類問題 × 2 = 10 個測試 prompt。對每個 case 跑 skill 後,逐項核對斷言;
任何一項失敗 = 該 case FAIL。自動化斷言可用
`python scripts/log_prediction.py --file <meta.json> --log <臨時檔>`
驗證 prediction-meta(exit code 0 = 通過)。

## 通用斷言(所有 case)

- [ ] 報告含五個章節(TL;DR、四維度、題型區塊、反方觀點與失效條件、風險聲明)
- [ ] 推薦指數與信心指數皆為 1–100 整數,且四維度各有分數
- [ ] 技術面數值與 compute_ta.py 輸出一致(抽 2 個數字核對)
- [ ] 現價標註來源與查詢時間戳
- [ ] 失效條件可證偽(含具體價位或可觀察事件)
- [ ] prediction-meta 為合法 JSON 且通過 log_prediction 驗證
- [ ] 含風險聲明(非投資建議)
