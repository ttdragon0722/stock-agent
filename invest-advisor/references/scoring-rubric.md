## 0. 來源分層(評分論據的可信度等級)

| 層級 | 來源 | 評分中的地位 |
|:---:|------|------|
| A | 官方一手:MOPS 重大訊息/月營收、TWSE/TPEx 籌碼數據(fetch_chips/fetch_mops)、公司財報、監管公告 | 最高權重;與 B/C 衝突時以 A 為準 |
| B | 主流財經媒體(經濟日報、工商時報、鉅亨網、Reuters、Bloomberg 等) | 正常論據;注意台媒同質性(互相轉載不算獨立來源) |
| C | 券商內容行銷、訂閱自媒體(PressPlay 等)、論壇/社群 | **僅可作情緒溫度計,不得作為任一維度評分的獨立論據** |

- 消息面評分的論據**至少一半須來自 A/B 級**;僅有 C 級支撐的論點
  不計入評分,只能寫進「市場情緒」描述
- 台股標的:fetch_chips 的法人買賣超與融資變化屬 A 級證據,
  外資連續買/賣超與新聞敘事矛盾時,以籌碼數據為準並寫入多空對辯

## II. 各維度評分錨點(1–100)

先定位區間,再依證據強度在區間內微調。每個分數都必須能指出對應證據。

### 消息面
| 區間 | 錨點 |
|------|------|
| 80–100 | 重大正面催化劑(財報大幅超預期、獲監管批准、重量級合作)且無未消化利空 |
| 60–79 | 正面消息為主,催化劑可期(財報將至、產品發布),小型利空已被市場消化 |
| 40–59 | 消息面混雜或平靜,無明確催化劑 |
| 20–39 | 負面消息為主(下修指引、訴訟、監管調查),短期難反轉 |
| 1–19 | 重大利空進行中(退市風險、詐欺指控、崩盤級事件) |

### 技術面(全部證據必須來自 compute_ta.py 輸出,見 ta-checklist.md)

> **機械錨定(1.2.0)**:compute_ta.py 每個時框輸出 `suggested_score`
> (由確定性規則合成的建議分數與 ±5 區間)。技術面最終分數以**主時框**
> 的 suggested range 為錨:落在區間內免說明;偏離必須寫明具體理由
> (如型態證據、跨時框結構),且**偏離不得超過 10 分**。
> 多時框衝突條款(ta-checklist §3,壓 40–59 + 信心 −15)優先於本條。

| 區間 | 錨點 |
|------|------|
| 80–100 | 多時框同向上升趨勢 + 動能確認(RSI 50–70、MACD 多頭)+ 量增 |
| 60–79 | 主時框上升趨勢但有背離或逼近壓力位;或下跌趨勢出現可信的反轉結構 |
| 40–59 | 區間震盪、均線糾結、訊號互相矛盾 |
| 20–39 | 主時框下降趨勢,反彈乏力(RSI < 45、MACD 空頭、量縮反彈) |
| 1–19 | 多時框同向下跌 + 跌破關鍵支撐 + 放量下殺 |

### 基本面(股票)
| 區間 | 錨點 |
|------|------|
| 80–100 | 營收/EPS 高成長 + 估值低於同業或歷史區間 + 現金流健康 |
| 60–79 | 成長穩健,估值合理(PEG ≈ 1 或同業中位數) |
| 40–59 | 成長平緩或估值偏高,兩者互相抵銷 |
| 20–39 | 成長停滯 + 估值偏高,或財務槓桿惡化 |
| 1–19 | 營收衰退、燒錢無止境、資不抵債疑慮 |

基本面(加密貨幣)→ 換成鏈上活躍度、代幣經濟、TVL 趨勢,見 crypto-specific.md。

### 宏觀環境

> **大盤趨勢錨定(1.2.0)**:錨點中「大盤上升/下跌趨勢」的判斷**必須**
> 引 benchmark 的 compute_ta 輸出(股票 SPY;台股另跑 ^TWII 或 0050.TW;
> 加密貨幣 BTCUSDT——K 線本來就已強制抓取,多跑一次 compute_ta 即可),
> 禁止憑新聞印象認定大盤方向。利率環境、板塊資金流仍以 WebSearch 佐證。

| 區間 | 錨點 |
|------|------|
| 80–100 | 利率環境順風 + 大盤上升趨勢 + 所屬板塊資金流入 |
| 60–79 | 大盤中性偏多,板塊不逆風 |
| 40–59 | 宏觀訊號混雜 |
| 20–39 | 大盤下跌趨勢或板塊資金流出 |
| 1–19 | 系統性風險進行中(流動性危機、政策急轉) |

## III. 推薦指數解讀

80–100 強烈看多 ｜ 60–79 偏多 ｜ 40–59 中性觀望 ｜ 20–39 偏空 ｜ 1–19 強烈看空

## IV. 信心指數(獨立於方向,1–100)

**起算:70 分**,依下列規則調整,禁止無理由的高信心:

| 調整 | 條件 |
|------|------|
| −15 | 任兩維度分數相差 ≥ 40(訊號嚴重矛盾) |
| −10 | 任一關鍵數字(**含現價**)只有單一來源可查 |
| −10 | 消息面論據過半僅有 C 級來源支撐(見 §0 來源分層) |
| −10 | 冷門標的:新聞 < 3 則或 OHLCV 不足 200 根 |
| −10 | compute_ta 輸出 stale_bars > 3(資料過時) |
| −5  | 財報/重大事件在 horizon 內(結果二元化) |
| −5  | 台股官方數據(fetch_chips/fetch_mops)不可用,籌碼敘事僅剩媒體轉述 |
| −10 | **校準回饋(1.2.0)**:recall_history 輸出的 `calibration.overconfident_buckets` 含本筆信心所屬分桶(桶 n ≥ 10 且平均信心 − 實際勝率 ≥ 15 個百分點);已判定 < 20 筆時本條不觸發 |
| +10 | 四維度全部同向(全部 ≥ 60 或全部 ≤ 40) |
| +5  | 關鍵數字全部雙來源一致 |

上限 90(永遠保留不確定性),下限 10。**信心 < 40 時報告必須明說
「資訊不足,本判斷參考價值有限」。**

## V. 交易計畫規則(Q1 / Q4)

- 進場區間、SL、TP 必須錨定 compute_ta 的支撐/壓力/ATR,不得憑空給整數關卡
- SL 建議:關鍵支撐下方 0.5–1.0 × ATR14;TP1:最近壓力位;TP2:延伸目標
- **R:R = (TP1 − 進場中點) / (進場中點 − SL),< 1.5 必須建議放棄或等待**
- 驗證框架的保守判定寫在 verify_predictions.py,給價位時要意識到:
  先觸 SL 判 LOSS、同根 K 棒雙觸判 LOSS、未進場判 NOT_FILLED、
  跳空越過 SL 以開盤價計出場(虧損不會被低估);無交易計畫的方向判斷
  須突破 horizon 縮放的雜訊帶(14 天約 ±1%)才計入準確率,
  neutral 的容許帶同樣隨 horizon 以 √t 縮放(30 天 ±5% 為基準)
