# 加密貨幣特有面向

標的為加密貨幣時,在標準四維度之上補充以下資料點。
這些屬於「基本面」與「宏觀面」的原料,權重見 scoring-rubric.md
(幣:技術 35% / 消息 25% / 基本 25% / 宏觀 15%)。

## 1. 基本面替代指標(取代 PE/營收)

| 指標 | 來源(WebSearch) | 判讀 |
|------|------|------|
| 鏈上活躍地址 / 交易數趨勢 | Glassnode、Artemis、區塊瀏覽器 | 價漲量(鏈上)縮 = 投機驅動,扣分 |
| TVL 趨勢(DeFi 類) | DefiLlama | TVL 與幣價背離 = 警訊 |
| 代幣經濟 | 官方文件、Tokenomist | 未解鎖量 > 流通量 20% 且 horizon 內有大額解鎖 → 基本面 ≤ 40 |
| 開發活動 | GitHub commits、Electric Capital | 長期持有(Q2)必查 |
| 穩定幣供給變化 | DefiLlama stables | 全市場流動性 proxy(宏觀面) |

## 2. 衍生品與情緒

| 指標 | 判讀 |
|------|------|
| 資金費率 Funding Rate | 極端正(>0.05%/8h)= 多頭擁擠,回調風險;極端負 = 空頭擁擠,軋空燃料 |
| 未平倉量 OI | 價漲 OI 增 = 趨勢健康;價跌 OI 增 = 空頭加碼 |
| 恐懼貪婪指數 | <20 極度恐懼(反向偏多)、>80 極度貪婪(反向偏空);只作情緒背景,不單獨定方向 |
| 清算地圖 | 密集清算區常成為价格磁吸目標,可輔助 TP/SL 定位 |

## 3. 宏觀面(幣圈版)

- **BTC 主導率(BTC.D)**:上升 = 資金避險回流 BTC,山寨幣逆風
  → 分析非 BTC 標的時,BTC.D 趨勢直接進宏觀分數
- BTC 自身趨勢:山寨幣的 beta 來源;BTC 下跌趨勢中,任何山寨的
  宏觀分數上限 45
- 美元流動性 / 利率預期、ETF 資金流(BTC/ETH 現貨 ETF 淨流入)
- 監管事件:SEC 訴訟、穩定幣立法、交易所出事 → 消息面直接反映

## 4. 執行差異

- OHLCV 用 Binance(fetch_ohlcv.py --asset-type crypto),
  自動轉 USDT 交易對;支援 4h,多時框 = 1w / 1d / 4h
- benchmark = BTCUSDT(分析 BTC 本身時 benchmark 仍為 BTCUSDT,
  超額報酬自然為 0,以方向準確率為主要驗證指標)
- 7×24 交易:horizon_days 是日曆日,無交易日換算問題
- 高波動:atr_pct 常 >5%,SL 距離按 ATR 給,勿套用股票的百分比直覺
- 冷門小市值幣:流動性與資料稀缺 → 信心指數按 rubric §IV 調降,
  且報告必須警示滑價與操縱風險
